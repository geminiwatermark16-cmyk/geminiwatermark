Gemini or Google Flow watermark still showing?

If a visible Gemini, sparkle or Veo watermark is still appearing on your export, check the plan tier, region, product surface and the actual source file before assuming the export is broken.

Updated Aug 20, 2026•5 min read

1. Check whether a visible watermark is expected for your Flow tier

Google Flow says all Veo and Imagen outputs include invisible SynthID. Visible watermark rules are separate: videos generated on Free, Plus and Pro tiers can include a visible watermark, while Ultra outputs may avoid the visible watermark except where local regulations require one.

ImportantA visible watermark and SynthID are not the same thing. Removing or avoiding a visible mark does not remove the invisible provenance signal.

2. Your region can change the visible-watermark behavior

Watermark requirements can vary by local regulation. This means two users on similar accounts may not always see identical export behavior in different countries or regions. If you are on a premium tier and still see a visible mark, confirm the policy for your location before troubleshooting the file itself.

3. Confirm you are using the correct Google account and plan

If you have multiple Google accounts open, Flow may be running under a different account from the one with your paid plan. Check the active account in Flow and the account that owns the Google One subscription. If the entitlement looks wrong, sign out of the extra accounts, reopen Flow and verify the active plan again.

4. Check whether the watermark is baked into an older export

Changing a plan, account or generation setting does not rewrite a file that is already saved on your device. If the visible mark is present in an older MP4, WebM, MOV, PNG or JPG, that exported file will keep the mark until you regenerate the media or edit the existing file.

For a file you own or are authorized to edit, use the Gemini watermark removal guide to identify whether the visible profile is supported.

5. Flow watermark still showing on an Ultra account

If your account should receive an export without a visible watermark but the mark still appears, first verify the active subscription, country or region, generation product and source file. If the entitlement appears wrong, use Flow's official feedback or support path because account-level plan recognition cannot be fixed by editing the downloaded file.

6. Keep the original export before trying cleanup

If you need to work with an already-exported video, keep the original file. Cropping, resizing or repeatedly re-encoding the clip can move the watermark area and reduce cleanup quality. For recent portrait exports, keep the native 9:16 dimensions whenever possible.

Use the Google Flow watermark remover guide for supported Flow exports, or the Gemini video watermark remover guide for current Gemini and Veo profiles.

Gemini image watermark still showing

Image behavior can differ from Flow video behavior. If a downloaded Gemini image already contains a visible logo or sparkle, the mark may be part of the saved pixels. For supported JPG, PNG and WebP files that you own or can edit, the Gemini image watermark remover page covers the browser workflow.

FAQ

Why is my Google Flow watermark still showing?

Visible-watermark behavior can depend on tier, region and the product used. Also check whether you are viewing an older file that was exported before your account or plan changed.

Does Ultra guarantee no visible watermark everywhere?

No universal guarantee should be assumed. Google notes that Ultra videos can still contain a visible watermark when local regulations require it.

Does Flow still use SynthID without a visible logo?

Yes. Google states that Flow outputs made with Veo and Imagen include invisible SynthID.

Can I clean an already-exported file?

Supported visible profiles can be processed if you own or are authorized to edit the file. Image cleanup is free; supported video processing requires the active 30-day video plan.
