Best practices for supported visible Veo watermark cleanup on 1080×1920 and 1920×1080 source files.

For 1080p Veo exports, resolution matters because watermark position is tied to the frame. A portrait 1080×1920 file and a landscape 1920×1080 file should not be treated as the same layout.

Use the original source dimensions

Avoid resizing before cleanup. Scaling can shift the expected mark location and reduce reconstruction quality around edges.

Pick the legacy Veo profile when appropriate

Older supported Veo exports use a different visible mark from newer Gemini diamond layouts. Use the Veo watermark remover guide to choose the matching profile.

Preview motion, not just one frame

Inspect several seconds of the cleaned area. Moving clothing, text, leaves and background edges can expose artifacts that are not visible in a single still frame.
