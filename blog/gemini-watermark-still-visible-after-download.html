TROUBLESHOOTING

Gemini watermark still visible after download?

Check the source file, watermark profile, resolution and current Gemini/Flow watermark behavior before trying another cleanup.

If a visible Gemini watermark remains after download, the cause is often a mismatched profile or a changed source file rather than a failed download.

Check whether the file was resized

A watermark profile calibrated for 1080×1920 may miss the same mark after the video is cropped or scaled.

Use the original export

Repeatedly processing an already-cleaned or recompressed copy can create artifacts. Return to the original Gemini or Flow export whenever possible.

Confirm the visible mark type

Recent Gemini diamond marks and legacy Veo layouts use different positions. See the full troubleshooting guide for profile and account checks.

Remember that old exports do not change automatically

If a platform setting changes later, a file already exported with a visible mark will still contain that overlay. You need the original media workflow or a supported cleanup step.

Retry from the original file

Upload the source video first and select the matching visible watermark profile.
